# Build TestTool

1. Open the Apache NetBeans IDE.
2. Open the mms_testtool project in Netbeans.
3. In NetBeans click Run on the top navigation bar and then press the "Clean and Build Project" dropdown button. A dist directory should have been created inside of the TestTool folder. Inside of this dist dir a jar file named TestTool should have been created.
4. Next, go back to Netbeans and click on the Files tab in between Projects and Services. It should be located directly under the navigation bar with 'New File', 'New Project', and 'Open Project'.
5. Under the TestTool folder, click the build.xml file and files should appear in the Navigator pane
6. Scroll down until you find packageTool. Right click run on packageTool -> Run Target.
7. In your dist dir other files should have now been generate. Double click on the run Windows Batch File and the test tool GUI should appear.
